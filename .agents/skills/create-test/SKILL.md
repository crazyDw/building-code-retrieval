# 新增测试

测试放 `project/tests`，用 pytest。根目录 `pyproject.toml` 已配好 `testpaths` 与 `pythonpath`，在仓库根目录直接跑 `pytest` 即可。

## 要求

- 文件 `test_*.py`、函数 `test_*`；一个用例只断言一件事，失败信息要能直接定位原因。
- **断言行为，不断言措辞**：不要用「输出包含某句话」验证逻辑。
- 只 mock 外部依赖（DeepSeek API、Milvus）；不要 mock 被测逻辑本身。
- 涉及数值的用例写成参数化表格，把「输入 → 期望」并排列出。
- 解析相关的用例用 `数据库上传资料/` 下的真实文件做夹具，不要另存改写版语料；
  需要构造异常形态时在测试内临时生成，不往语料目录写文件。

## 验证

- `pytest` 全绿。
- 新用例必须验证过「它在错误实现下会失败」——否则它证明不了任何事。
- 修缺陷时附一个能复现原问题的用例。
