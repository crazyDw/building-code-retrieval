# 层级判定规则与已知缺陷

## 五级层级

规范正文的层级为：**章 → 节 → 条 → 款 → 项**。判定依据是**行首文本的编号形态**，不是 `#` 标记的数量。

| 层级 | 行首形态 | 正则 | 样例 |
|---|---|---|---|
| 章 | 单段数字 | `^\d+(?:\s\|$)` | `1 总 则`、`4 设 计` |
| 节 | 两段数字 | `^\d+\.\d+(?:\s\|$)` | `3.1 混凝土` |
| 条 | 三段数字 | `^\d+\.\d+\.\d+\s` | `1.0.1 为规范民用建筑…` |
| 款 | 正文行首单段数字 | `^\d+\s+\S` | `1 应按照可持续发展的原则…` |
| 项 | 正文行首数字 + 右括号 | `^\d+[）)]` | `1）与镀锌钢材或铝材相接触部位…` |

**章与款同形**（都是「数字 + 空格」），靠位置区分：章在标题行（带 `#` 标记），款在正文行。

## 归属规则

- 条归属于最近的上级节；该章无节时直接归属其章（实测 3 处：民用建筑通用规范第 1 章，住宅项目规范第 1、5 章）。
- 款归属于最近的上一条；项归属于最近的上一个款。
- **项不单独成块**，整款（含其下所有项）作为一个块——项与款共享前置条件（如「严禁用于下列混凝土结构：」），拆开会丢失适用前提。

## 目次区间的界定

目次区间**不能靠「第一个章标题」界定**——目次条目本身可能带 `##` 标记并被章的模式匹配到。

正确做法：

1. 找到文本为 `目次`（允许 `目 次`）的标题行，作为区间起点。
2. **跳过行尾带页码的内容行**（`\s\d+\s*$`，如 `8 维护与拆除…… 19`）。
3. 区间终点 = 第一个既匹配章/节模式、又不带行尾页码的标题行。

区间内的所有行不参与层级与条款识别。

## 转换工具已知缺陷

PDF → Markdown 的输出在不同文件间形态不一，实测过以下四类：

| 缺陷 | 表现 | 后果 |
|---|---|---|
| 章标记混用 | 同一文件里部分章用 `#`、部分用 `##` | 按 `#` 数量判层级必然出错 |
| 章与节全同级 | 整份文件的章和节都用 `##` | 同上 |
| 目次条目带标记 | 目次里某条被写成 `## 8 维护与拆除…… 19` | 章数多算；正文起点被误定在目次内部 |
| 条文被标为标题 | `## 3.2.1 普通钢筋的材料分项系数…` | 该条从条款列表消失，条数少算 |

四类缺陷在首批 5 份语料中都实际出现过。**同一文件内的标记也可能不一致**（例如混凝土结构通用规范里 `3.2.1`~`3.2.3`、`4.4.7`~`4.4.14` 被标为标题，而 `3.2.4`、`4.4.10` 是正常条文），所以不能靠抽样判断，必须逐行分类。

## 条号连续性校验

校验时须放行两类跨章过渡，否则会把正常的章间切换误报为缺号：

- 有节的章：上一章末条 `X.Y.Z` → 下一章首条 `(X+1).1.1`
- 无节的章：上一章末条 `X.Y.Z` → 下一章首条 `(X+1).0.1`

判定规则：同节内要求 `C == c+1`；同章内跨节要求 `C == 1` 且 `B == b+1`；跨章只要求 `C == 1` 且 `A == a+1`。

## 标题内的版式残留空格

转换产物可能带匀字排版残留的空格（实测 `总 则`、`目 次`、`场 地`、`声 环 境`、`燃 气` 共 5 处）。

**保留在源文件中，由解析器在内存中归一化**后再用于章节路径与界面展示。清理源文件不在本技能范围内。
