# 文档索引

`docs/` 存放**工程约束与规范**。语料数据不在这里——它在 `数据库上传资料/`。

## 子目录

| 目录 | 内容 | 什么时候读 |
|---|---|---|
| `python-rules/` | Python 编码约束 | 写业务代码前 |
| `architecture/` | 架构分层、模块边界、数据流 | 决定模块归属或新增组件前 |
| `domain/` | 领域术语与业务规则 | 涉及规范层级、条号、检索块的语义时 |
| `api/` | 接口契约 | 改动或对接接口时 |
| `runbooks/` | 运维与排障 | 部署、故障、重建索引时 |
| `framework/` | 框架与库的落地要点 | 接入 FastAPI / Milvus / 模型库时 |

## 约定

- **文件级索引写在各自目录的 README**：`AGENTS.md` 只索引到子目录这一层；目录内新增文件时更新该目录的 README，不要改 `AGENTS.md`。
- **先改文档再改代码**：`api/`、`domain/` 这类契约与规则内容变更时，连同实现一起提交。
- **以需求为准**：与 `project-requirements/项目概况.md` 冲突时以《项目概况》为准，并回来修正本文档。
- **不抄手册**：框架细节查官方文档，这里只记录「本项目怎么用、踩过什么坑」。
