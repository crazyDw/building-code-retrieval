# 领域术语与业务规则

## 术语

### 规范层级（五级）

| 层级 | 行首形态 | 说明 |
|---|---|---|
| 章 | 标题行 + 单段数字 | `1 总则` |
| 节 | 标题行 + 两段数字 | `3.1 混凝土` |
| 条 | 行首三段数字 | `1.0.1 ...`，检索与引用的主粒度 |
| 款 | 正文行首单段数字 | 与「章」同形，靠位置区分 |
| 项 | 正文行首数字 + 右括号 | 不单独成块，依附所属款 |

判定依据是**行首编号形态**，不是 `#` 的数量。归属关系：条属于最近的上级节（章下无节时属于章），款属于最近的上一条，项属于最近的上一个款。

### 标识

| 标识 | 角色 |
|---|---|
| `clause_id` | 逻辑主键，标识「条」，如 `{标准号}_5.3.9` |
| `chunk_id` | 物理主键，标识检索块；一条可对多块 |
| `section_id` | 节标识；章下无节时退化为章号 |
| `table_id` | 表标识，如 `表 3.1.1-2` |

### 块类型

| 类型 | 含义 | 能否作为答案依据 |
|---|---|---|
| `body` | 条文正文 | 能 |
| `term` | 术语章条目 | 能（术语章属规范正文） |
| `table_row` | 表格行 | 能（随所属条文送入） |
| `scope` | 适用范围说明 | **不能**，只作条件限定 |

### 其他

- **全文强制性规范**：GB 550xx 系列，每条条文都有强制效力；命中时答案必须标注。
- **标准号**：由外部映射表提供，语料文件内与文件名均不含。
- **RRF**：dense 与 sparse 两路召回结果的融合方式，默认等权。
- **未命中阈值**：重排分低于该值即判未命中，用自动题库标定。已标定 `SCORE_THRESHOLD=-2.0`（2026-10-05：703 正样本 + 40 条超范围负样本；Youden 最优 −3.60，运营留 1.6 分余量）。
- **DEV_MODE**：开发模式，跳过模型加载与预热，使用 `_dev` 后缀数据源。

## 语料实测结论（2026-10-05）

> 对 `数据库上传资料/` 5 份语料的全文扫描；块级数字已由 M1 解析器复核。

- **无「术语」章节**：5 份均无。`term` 块类型保留实现，但 v1 没有真实数据；词典抽取以统计方法 + DeepSeek 生成为主，验收用合成用例。
- **无独立 `scope` 段落**：语料中没有「适用于」句式，「范围」全部出现在条文内部。`scope` 块保留实现与「不占 top10 名额」逻辑，验收用合成用例。
- **前置内容**：5 份均有「前言」「目次」——入库留存但不参与检索，验证覆盖全部 5 份。
- **层级计数**：33 章 / 91 节 / 554 条 / **436 款** / 7 项。普查脚本曾把 2 条带编号的表格注续行计为款（438）；按「注」属表格，解析器归入表注，款数精确为 436。
- **LaTeX**：97 处行内符号（混凝土 33 / 砌体 30 / 住宅 28 / 钢结构 5 / 民用 1）+ 砌体 3.4.2 一处 `$$…$$` 独立公式（保留原文）；表格 27 张、「注：」8 处、图片 0 处。

## 业务规则

1. **允许条件性推导，禁止下合规结论**；推导必须写明所用输入值。
2. 前言、目次入库留存但**不参与检索**；条文说明当前语料不含。
3. 表格的「注：」随该表一并可检索，但只能作条件限定。
4. 上下文超限时**整条丢弃**，不做单条截断。
5. `scope` 块不占 top10 名额，命中时作为限定条件附加。
6. 同一标准号只允许一个现行版；命中被替代的老标准时在答案末尾提示适用性。
7. 块长按实际块文本（含标准名与章节路径前缀）计 token，表格内容不计入；单个项自身超限时保留整项并记录例外，不劈项。
